题目解析

62.不同路径

一个机器人位于一个 m x n 网格的左上角 (起始点在下图中标记为 “Start”)。机器人每次只能向下或者向右移动一步。机器人试图达到网格的右下角 (在下图中标记为 “Finish”)。问总共有多少条不同的路径？

解析

  • 定义一个二维数组 dp，其中 dp[i][j] 表示从起点到达位置 (i, j) 的不同路径数。根据题意，初始化 dp[0][0] = 1，因为起点只有一种路径。然后使用两个循环遍历整个网格，对于每个位置 (i, j)，如果它不是障碍物，则 dp[i][j] = dp[i - 1][j] + dp[i][j - 1]，即当前位置的路径数等于上方和左方路径数之和。最后返回 dp[m - 1][n - 1] 即可。

63. 不同路径 II

一个机器人位于一个 m x n 网格的左上角 (起始点在下图中标记为 “Start”)。机器人每次只能向下或者向右移动一步。机器人试图达到网格的右下角 (在下图中标记为 “Finish”)。网格中有障碍物，障碍物和空位置分别用 1 和 0 来表示。问总共有多少条不同的路径？

解析

  • 这道题和上一题非常类似，只不过需要考虑障碍物的情况。定义一个二维数组 dp，其中 dp[i][j] 表示从起点到达位置 (i, j) 的不同路径数。根据题意，初始化 dp[0][0] = 1，如果起点是障碍物，则 dp[0][0] = 0。然后使用两个循环遍历整个网格，对于每个位置 (i, j)，如果它是障碍物，则 dp[i][j] = 0；否则 dp[i][j] = dp[i - 1][j] + dp[i][j - 1]，即当前位置的路径数等于上方和左方路径数之和。最后返回 dp[m - 1][n - 1] 即可。

343.整数拆分

给定一个正整数 n，将其拆分为至少两个正整数的和，并使用这些整数的乘积最大化。返回你可以获得的最大乘积。

解析

  • 定义一个数组 dp，其中 dp[i] 表示将整数 i 拆分为至少两个正整数的和所能获得的最大乘积。根据题意，初始化 dp[2] = 1，因为 2 可以拆分为 1 + 1，乘积为 1。然后使用一个循环从 3 到 n，对于每个整数 i，再使用一个循环从 1 到 i - 1，计算将 i 拆分为 j 和 i - j 的情况，即 dp[i] = max(dp[i], max(j * (i - j), dp[i - j] * j))。最后返回 dp[n] 即可。

96.不同的二叉搜索树

给定一个整数 n，求以 1 … n 为节点组成的二叉搜索树有多少种？

解析

  • 这道题的难点在于关系式的寻找。定义一个数组 dp，其中 dp[i] 表示以 1 … i 为节点组成的二叉搜索树的种类数。根据题意，初始化 dp[0] = 1，因为空树也是一种二叉搜索树。然后使用一个循环从 1 到 n，对于每个整数 i，再使用一个循环从 1 到 i，计算以 j 为根节点的情况，即 dp[i] += dp[j - 1] * dp[i - j]，其中 dp[j - 1] 表示左子树的种类数，dp[i - j] 表示右子树的种类数。最后返回 dp[n] 即可。
